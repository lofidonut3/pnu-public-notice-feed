PNU Public Notice Feed

Unofficial public metadata feed for public notices from Pusan National University. This project is not operated by Pusan National University.

This site publishes static, AI-friendly public notice metadata. It links back to official notice pages and attachment download URLs instead of mirroring full notice or attachment content.

Endpoints

  • index.json - compact manifest with sources, status, archive, same-notice groups, and diagnostics
  • events.json - primary recent event stream for cursor-based checks
  • latest.json - JSON Feed 1.1 compatible latest-discovery notice metadata
  • rss.xml - RSS 2.0 compatibility feed
  • archive/YYYY-MM.json - monthly durable archive files
  • openapi.json - static endpoint manifest
  • llms.txt - AI agent usage guide

Agent Notes

Use events.json as the primary cursor stream. Each event is a compact routing record with archive_file and archive_item_id for durable metadata lookup.

No project-specific client library is required. Any HTTP/JSON client can keep a local cursor and fetch archive files when detailed metadata is needed.

Use event duplicate fields or index.json.same_notice_groups before sending notifications for multiple matching items from different sources. Use latest.json for latest discovery and rss.xml for compatibility.
